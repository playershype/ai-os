AI Operating System para tu celular

Tu centro de mando diario. Lee tu Gmail, Google Calendar, Google Drive y Google Tasks y te muestra en una sola pantalla qué importa hoy, qué cambió, qué te deben y qué hacer después. Se aloja gratis en GitHub Pages y se usa desde el navegador del celular. No hay que instalar nada.

Consejo: haz los pasos 1 a 4 en una computadora (es mucho más fácil subir archivos y configurar Google ahí). Después, todo lo demás se hace en el celular.
Pasos 1. Crear tu cuenta de GitHub 2. Subir la app a GitHub 3. Publicarla con GitHub Pages 4. Crear tu “llave” de Google 5. Abrirla en el celular y conectar Google 6. Ponerla en la pantalla de inicio 7. Activar la IA (opcional, tiene costo) Cómo funciona cada día Solución de problemas Privacidad

1Crear tu cuenta de GitHub

  1. Entra a github.com/signup.
  2. Escribe tu correo, una contraseña y un nombre de usuario (anótalo — por ejemplo chief-ops). Tu app quedará en https://TU-USUARIO.github.io/ai-os/.
  3. Confirma el código que llega a tu correo. Si te pregunta por un plan, elige Free (gratis).

2Subir la app a GitHub

  1. Descomprime el archivo ai-os-web.zip (Windows: clic derecho → Extraer todo… → Extraer). Se crea una carpeta ai-os-web.
  2. Entra a github.com/new.
  3. Repository name: ai-os (exactamente así, en minúsculas).
  4. Marca Public (necesario para que GitHub Pages sea gratis — solo el código es público, tus datos nunca se suben).
  5. No marques nada más. Clic en Create repository.
  6. En la página que aparece, haz clic en el enlace uploading an existing file (o en Add file → Upload files).
  7. Abre la carpeta ai-os-web en tu computadora, selecciona todo lo que hay adentro (Ctrl+A en Windows, Cmd+A en Mac) y arrástralo a la página de GitHub. Usa Chrome o Edge para que se suba también la carpeta js.
  8. Espera a que termine la lista de archivos. Revisa que aparezcan index.html, app.js y la carpeta js.
  9. Abajo, clic en el botón verde Commit changes.
Importante: index.html debe quedar en la “raíz” del repositorio (en la primera página), no dentro de otra carpeta. Si ves una carpeta ai-os-web en GitHub, borra el repositorio y vuelve a subir solo lo que hay dentro de ella.

3Publicarla con GitHub Pages

  1. En tu repositorio ai-os, clic en Settings (arriba, a la derecha).
  2. En el menú de la izquierda, clic en Pages.
  3. En Build and deployment → Source, elige Deploy from a branch.
  4. En Branch, elige main y la carpeta / (root). Clic en Save.
  5. Espera 1–2 minutos y recarga la página. Arriba aparecerá: “Your site is live at https://TU-USUARIO.github.io/ai-os/”.
  6. Abre ese enlace. Debes ver la pantalla Welcome to your AI Operating System. Puedes tocar Load demo data para probarla con datos de ejemplo (marcados como DEMO y ficticios).

4Crear tu “llave” de Google gratis

Google exige que cada app que lee Gmail tenga su propia llave (un “Client ID”). Como la app es tuya, la creas tú. No necesitas tarjeta.

4a. Proyecto

  1. Entra a console.cloud.google.com/projectcreate con la cuenta de Google que quieres conectar.
  2. Acepta los términos si te los pide. Project name: AI OS → Create. Espera unos segundos.
  3. Arriba, en el selector de proyecto, verifica que diga AI OS.

4b. Activar las 4 APIs

Abre cada enlace, verifica que arriba diga AI OS y pulsa el botón azul Enable (Habilitar):

  • Gmail API
  • Google Calendar API
  • Google Drive API
  • Google Tasks API

4c. Pantalla de inicio de sesión

  1. Abre Google Auth Platform → Get started.
  2. App name: AI OS · User support email: tu correo → Next.
  3. Audience: External → Next.
  4. Contact information: tu correo → Next → marca I agree → Continue → Create.
  5. Abre Audience → en Test users clic en + Add users → escribe tu propio Gmail → Save.

4d. Crear la llave (Client ID)

  1. Abre Clients → + Create client.
  2. Application type: Web application. Nombre: AI OS web.
  3. En Authorized JavaScript origins → + Add URI → escribe (con tu usuario, sin barra al final):
    https://TU-USUARIO.github.io
  4. En Authorized redirect URIs → + Add URI → escribe (con barra al final):
    https://TU-USUARIO.github.io/ai-os/
  5. Clic en Create. Copia el Client ID (termina en .apps.googleusercontent.com). Puedes enviártelo por correo o WhatsApp a ti mismo para pegarlo en el celular. No necesitas el “Client secret”.
La app también te muestra estas dos direcciones exactas, con botón Copy, en Settings → Google account.

5Abrirla en el celular y conectar Google

  1. En el celular, abre https://TU-USUARIO.github.io/ai-os/ en Safari (iPhone) o Chrome (Android).
  2. Si cargaste datos de demo, no pasa nada: se borran solos al conectar Google.
  3. En el paso 1 (o en Settings), pega tu Client ID → Save.
  4. Toca Connect Google y elige tu cuenta.
  5. Google dirá “Google no ha verificado esta app”. Es normal: es tu propia app privada. Toca Continuar.
  6. En la pantalla de permisos, marca todas las casillas → Continuar.
  7. Vuelves a la app y empieza a sincronizar. Sigue los pasos: tu nombre y hora del resumen, algunas reglas de prioridad, y Generate my first brief.

6Ponerla en la pantalla de inicio

  • iPhone (Safari): toca el botón Compartir (cuadrado con flecha hacia arriba) → Agregar a pantalla de inicio → Agregar.
  • Android (Chrome): toca ⋮ (arriba a la derecha) → Agregar a la pantalla principal → Agregar.

Ahora tienes el ícono AI OS como cualquier otra app.

7Activar la IA opcional · tiene costo

Sin IA la app ya funciona con reglas: detecta fechas límite, choques de agenda, correos que esperan respuesta, promesas simples (“te lo envío el viernes”), estado de proyectos y cambios desde ayer. Con IA, además:

  • escribe un resumen interpretado, marcando cada línea como FACT (hecho), INFERENCE (deducción) o RECOMMENDATION (recomendación);
  • clasifica mejor el correo y encuentra compromisos y decisiones (siempre verificados contra las palabras exactas del correo);
  • prepara reuniones, redacta respuestas y contesta cualquier pregunta en Chief of Staff.
  1. Entra a console.anthropic.com/settings/keys y crea una cuenta.
  2. En Billing, carga un poco de saldo. Se cobra por uso; revisa los precios actuales en la misma página.
  3. Clic en Create key, cópiala y pégala en la app: Settings → AI → Save & test.

Cómo funciona cada día

  • Abre la app por la mañana. La primera vez que la abras después de tu hora (por defecto 6:00 AM), sincroniza, compara con ayer y genera tu resumen en unos segundos.
  • La sesión de Google dura cerca de 1 hora. Si pasó más tiempo, al abrir la app verás un salto rápido a Google y de vuelta (normalmente sin escribir nada). Puedes desactivarlo en Settings y usar el botón Refresh Google.
  • Mientras la app está abierta, revisa novedades cada 15 minutos.
  • Limitación honesta: un celular no deja que una página web trabaje en segundo plano, así que no puede avisarte a las 6 AM si no la abres. Tu último resumen siempre queda guardado y se ve aunque no tengas señal.
  • Si también quieres usarla en la computadora, ábrela ahí y conecta Google de nuevo (cada dispositivo guarda sus propios datos).

Privacidad

  • En GitHub solo está el código de la app. Tus correos, agenda y llaves nunca se suben a GitHub: se guardan solo en el navegador de tu celular.
  • Tus datos viajan directamente de tu celular a Google (y a Anthropic si activas la IA). No pasan por ningún otro servidor.
  • El acceso a Google es de solo lectura: la app no puede enviar, cambiar ni borrar correos, eventos, archivos ni tareas de Google. Las respuestas se redactan para que tú las copies y envíes desde Gmail.
  • No publiques páginas de otras personas en tu misma cuenta de GitHub Pages (comparten el mismo espacio del navegador).
  • Puedes quitar el acceso cuando quieras en myaccount.google.com/permissions.
